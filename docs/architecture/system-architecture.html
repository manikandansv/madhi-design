Phase 3
🔎
Elasticsearch
Transaction search index
  • Full-text merchant search with fuzzy matching
  • Faceted filter: category + amount range + date
  • Aggregations — spend per category per month (dashboard)
  • Synced from MongoDB via Kafka consumer
Phase 5
🏔
Cassandra
Conditional only
  • High-volume time-series write throughput at scale
  • Not introduced until Postgres partitioning is measurably insufficient
  • Significant ops overhead — justify with real data before adding
Phase 5+ · conditional
🌊 Streaming Platform
Event backbone · real-time pipeline
⚙
Apache Kafka
Durable event log
  • statements.uploaded → parsing worker
  • transactions.parsed → MongoDB, ES indexer, alert engine
  • alerts.fired → notification + event log
  • milestones.approved → audit + ML training sink
  • Replaces Redis Streams in Phase 4
  • Replay capability — rebuild ES index without re-parsing PDFs
Phase 4
⚡
Kafka Streams
Real-time pipeline (embedded)
  • Transaction categorization pipeline — lookup → AI fallback for unknowns
  • 30-day rolling variance window per category per user
  • Windowed state embedded in app process — no separate cluster
  • Emits to alerts.fired when variance exceeds threshold

  • Flink's distributed cluster adds ops complexity without benefit at this scale

AI Wrapper — Evolution by Phase
Phase 1
Prompt + Agentic entry
Structured output via tool_use. indian-finance.md is the domain layer. 2-turn clarification loop (client-side). AgentRunner interface defined now — activated in Phase 4.
Phase 3–4
+ RAG + Agentic pipeline
pgvector replaces static md file for tax/EPF/NPS rules — retrieves only relevant sections. AgentRunner activated for PDF statement parsing agent.
Phase 5+
+ Fine-tuning + Alert agent
Approved/skipped decisions → labelled training set. Alert investigation agent added. Fine-tuned model added as new ProviderClient implementation.
Long term
Distilled model
Fine-tuned outputs train a smaller domain-specific model. Lower cost, lower latency. One more ProviderClient implementation — nothing else changes.
